## Run
1. `npm install`
2. `npx playwright install chromium`
3. Set `AGENT_USER` and `AGENT_PASSWORD` in the shell (do not commit credentials).
4. `npm run test:smoke`
5. `npm run test:regression`
6. `npm run report`

Base URL defaults to `http://127.0.0.1:8081`.
